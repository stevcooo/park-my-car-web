# park-my-car-web

Skopje parking-by-SMS helper: pick a vehicle, provider, zone and duration, then open the prepared `sms:` link.

The web app lives at the repo root and is built with [Vite](https://vitejs.dev/). The Expo mobile port lives in `mobile/`.

## Available Scripts

In the project directory, you can run:

### `npm run dev` (or `npm start`)

Runs the app in development mode.\
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

The page reloads when you make changes.

### `npm run build`

Builds the app for production to the `dist` folder.\
It bundles React in production mode and optimizes the build for the best performance.

### `npm run preview`

Serves the production build from `dist` locally for a final check.
